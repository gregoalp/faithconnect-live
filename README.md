# FaithConnect

A faith-centered web application that helps people meet new friends and connect through Bible topics, Christian life, and shared interests.

## Live Demo

[Visit FaithConnect](https://faithconnect-chat.vercel.app/)

## Features

- Bible topic selection
- One-on-one user matching
- Real-time chat
- Report and block options
- Leave a conversation and find someone new

## Technologies Used

- React
- Vite
- Node.js
- Express
- Socket.IO
- Database: specify the database used in production

## Project Purpose

FaithConnect was developed to provide a simple way for people to start meaningful conversations about faith and Christian life.
